## 🌟 Overview

**Jarvis** is a lightweight and intelligent Python voice assistant designed to perform basic voice-activated tasks using natural language commands. Created as part of an internship at **CodeAlpha**, this assistant demonstrates core voice interaction capabilities such as:

🔹 Greeting the user  
🔹 Responding with a custom creation date  
🔹 Opening popular websites (Google, YouTube, Facebook, WhatsApp, Instagram)  
🔹 Exiting via voice commands like "exit", "quit", or "leave"

---

## 🧰 Tech Stack

- 🐍 **Python 3.x**
- 🗣️ **SpeechRecognition** – Convert speech to text
- 🔊 **pyttsx3** – Convert text to speech (TTS)
- 🎙️ **pyaudio** – Microphone input
- 🌐 **webbrowser** – Open URLs directly in your browser

## 📥 Installation Guide

### 🔧 1. Clone this Repository

```bash
git clone https://github.com/Waqas-Khan-CodeCanvas/codeAlpha-tasks.git
cd codeAlpha-tasks
```

### 📦 2. Install Required Dependencies

```bash
pip install pyttsx3 pyaudio SpeechRecognition
```

> ⚠️ **Note:** Having trouble installing `pyaudio`? Check the [official PyAudio installation page](https://people.csail.mit.edu/hubert/pyaudio/#downloads) for platform-specific solutions.

## ▶️ Getting Started

Start your assistant with:

```bash
python jarvis.py
```

### 🗨️ Try Saying:
- "Jarvis"
- "Open YouTube"
- "What's your age?"
- "Exit"
